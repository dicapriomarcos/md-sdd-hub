## Remotes

URL sin credenciales. «Cuándo se sube» decide si la IA puede hacer push sola.

| Remote | URL | Rama | Cuándo se sube |
|---|---|---|---|
| origin | … | main | Cuando la persona lo pida |
| dev | … | develop | Cuando la persona lo pida |
| pro | … | main | **Solo con autorización expresa en ese momento** |
