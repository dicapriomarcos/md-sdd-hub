## 1. Síntoma

Qué se observa, dónde, desde cuándo y a quién afecta. Pasos para reproducirlo:

1. Paso.
2. Resultado esperado / resultado real.

## 2. Causa raíz

Por qué ocurre, con referencia a archivos, funciones o commits. Si aún no se conoce, deja las hipótesis.

## 3. Solución

Qué se cambia y por qué esa solución y no otra.

## 4. Prevención

Qué se añade para que no vuelva a pasar: tests, validaciones, alertas, cambios de proceso.

## 5. Criterios de verificación

- [ ] AC-01 · El error ya no se reproduce con los pasos del síntoma.
- [ ] AC-02 · Hay un test automatizado que cubre el caso.

## 6. Plan de tareas

- [ ] T-01 · Reproducir el error con un test que falle.
- [ ] T-02 · Aplicar la solución.
