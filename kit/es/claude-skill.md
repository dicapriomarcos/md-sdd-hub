# Documentación SDD (MD SDD Hub)

Las reglas de este proyecto son comunes a todos los agentes de IA y están en **`.sdd/instrucciones.md`** (en la raíz del proyecto), con las plantillas en `.sdd/plantillas/`.

Antes de crear o modificar cualquier spec, decisión de diseño, ADR o fix, y antes de implementar una funcionalidad, **lee `.sdd/instrucciones.md` completo y síguelo al pie de la letra**. Este archivo es solo un acceso para que Claude Code las cargue en el momento adecuado; no contiene reglas propias.

Responde, escribe y habla siempre en español.
