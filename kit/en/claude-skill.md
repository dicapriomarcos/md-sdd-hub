# SDD documentation (MD SDD Hub)

This project's rules are shared by every AI agent and live in **`.sdd/instructions.md`** (at the project root), with the templates in `.sdd/templates/`.

Before creating or changing any spec, design decision, ADR or fix, and before implementing a feature, **read `.sdd/instructions.md` in full and follow it to the letter**. This file is only an entry point so Claude Code loads them at the right time; it contains no rules of its own.
